# Modes

- Project mode adds nothing of Eva's to the session.
- An untrusted clone loads only the user's settings until the person trusts it. Store only the person's own answer.
- Assistant skills live only in the vault's `.eva/skills/`, never at the vault root: root skills reach every project session (lesson 5).
- A vault never holds a `CLAUDE.md`: it stops Claude Code from loading `AGENTS.md` (lesson 112).
- Pin each mode option with a contract test.
