# Vault

A personal knowledge vault for [Eva](https://github.com/guplem/eva). Keep this repository private.

- `AGENTS.md` says where each kind of note goes. Eva creates folders and notes as the vault grows.
- `.eva/assistant.md` holds your rules for Eva. Edit it, or ask Eva to change it.
- Eva saves and pushes this repository by herself. You can still edit it on any device and push.
